导出表

导出表与导入表相反，是描述导出表所在的PE文件向其他程序提供的可供调用的函数情况。PE中的导出表存在于动态链接库文件里。导出表的主要作用是将PE中存在的函数引出到外部，以便其他人可以使用这些函数，实现代码的重用。

一个简单的壳

未脱壳的程序代码：

.data
    g_szHello db 'Hello World!', 0
    g_szTitle db 'Hello', 0
.code
_main:
    
    invoke MessageBox, NULL, offset g_szHello, offset g_szTitle, MB_OK
    invoke ExitProcess, 0
    ret
end _main

节表

PE文件中所有节的属性都被定义在节表中，节表由一系列的IMAGE_SECTION_HEADER结构排列而成，每个结构用来描述一个节，结构的排列顺序和它们描述的节在文件中的排列顺序是一致的，全部有效结构的最后以一个空的IMAGE_SECTION_HEADER结构作为结束，所以节表中IMAGE_SECTION_HEADER结构数量等于节的数量+1。节表总是被存放在紧接着PE文件头的地方。
